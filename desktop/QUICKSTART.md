# 🚀 Quick Start Guide

## ⚡ 5-Minute Setup

### Step 1: Install Python (if not installed)

**Windows:**

```
Download from: https://www.python.org/downloads/
During installation: CHECK "Add Python to PATH"
```

**Linux:**

```bash
sudo apt update
sudo apt install python3 python3-pip
```

### Step 2: Install Dependencies

```bash
pip install -r requirements.txt
```

### Step 3: Run Application

```bash
python main.py
```

Done! The application should now open.

---

## 🎯 First Use

### Encrypt Your First URL:

1. **Click the "🔒 Encrypt" tab**

2. **Enter URL:**

   ```
   https://example.com/mypage
   ```

3. **Leave password empty** (for now)

4. **Click "🔒 Encrypt URL"**

5. **You'll get Persian text like:**

   ```
   ابجدهوزحطیکلمنسعفصقرشتثخذضظغآأإؤئة۱۲۳۴۵
   ```

6. **Click "📋 Copy"** to copy to clipboard

### Decrypt the Text:

1. **Click the "🔓 Decrypt" tab**

2. **Paste the Persian text**

3. **Leave password empty**

4. **Click "🔓 Decrypt URL"**

5. **Original URL appears!**

6. **Click "🌐 Open URL"** to open in browser

## 💡 Common Questions

### Q: Can I encrypt without password?

**A:** Yes! Leave password field empty for quick encryption.

### Q: Is my data sent online?

**A:** No! Everything works 100% offline.

### Q: What if I forget my password?

**A:** URL cannot be recovered. Always remember your password!

### Q: Can others decrypt without password?

**A:** If no password was used, yes. With password, only password holders can decrypt.
